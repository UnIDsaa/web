# 드랍 주기 타이머 (PWA)

## 왜 그냥 파일을 열면 안 되나요?
알림바에서 "체크/중지" 버튼을 누르는 기능은 서비스워커(Service Worker) 기술을 쓰는데,
이건 브라우저 보안 정책상 **HTTPS로 호스팅된 주소**에서만 동작합니다.
`index.html`을 폰에서 그냥 열면 타이머 자체는 잘 작동하지만, 알림바 컨트롤은 동작하지 않아요.

## 가장 쉬운 배포 방법: GitHub Pages (무료, 5분)

1. https://github.com 에서 계정 생성 (이미 있으면 생략)
2. 우측 상단 `+` → `New repository` 클릭 → 이름 아무거나 (예: `drop-timer`) → `Create repository`
3. 방금 만든 저장소 페이지에서 `Add file` → `Upload files` 클릭
4. 이 폴더 안의 파일 전부(`index.html`, `manifest.json`, `sw.js`, `icons` 폴더 통째로)를 드래그해서 업로드 → `Commit changes`
5. 저장소의 `Settings` → 왼쪽 메뉴 `Pages` → `Build and deployment` → `Branch`를 `main`으로 선택 → `Save`
6. 1~2분 기다리면 상단에 `https://내아이디.github.io/drop-timer/` 같은 주소가 생김
7. **폰 크롬으로 그 주소 접속** → 우측 상단 점 3개 메뉴 → `홈 화면에 추가` (또는 자동으로 뜨는 설치 배너)
8. 앱처럼 홈 화면에서 실행 → "🔔 알림바 컨트롤 켜기" 버튼 눌러서 알림 권한 허용

## 더 간단한 대안: Netlify Drop
1. https://app.netlify.com/drop 접속 (로그인 불필요)
2. 이 폴더 전체를 그대로 드래그 앤 드롭
3. 바로 https 주소가 생성됨 → 그 주소를 폰 크롬에서 열기

## 사용 흐름
1. 게임과 이 앱을 홈 화면에서 각각 실행 가능한 상태로 둠
2. 앱 켜고 "🔔 알림바 컨트롤 켜기" 한 번 눌러서 알림 권한 허용 (최초 1회)
3. "시작" 누르고 게임으로 전환
4. 2:00~2:40 구간 진입 시 진동 + 소리 + 알림바 알림이 뜸
5. 알림을 내려서 **앱으로 안 들어가고** "✅ 체크" 버튼만 탭 → 게임 화면 그대로 유지된 채 랩타임 기록 + 타이머 리셋
6. 끝낼 땐 알림의 "⏹ 중지" 또는 앱에서 직접 중지

## 제약사항 (솔직하게)
- 브라우저 탭/PWA가 완전히 강제 종료되면 타이머도 멈춥니다. "최근 앱" 목록에서 스와이프로 꺼버리면 안 돼요.
- 안드로이드가 배터리 절약 등으로 백그라운드 탭을 오래(수십 분 이상) 재운 경우, 알림이 늦게 오거나 안 올 수 있습니다.
- 진짜 "다른 앱 위에 겹쳐서 뜨는 오버레이"는 아닙니다. 알림바를 통한 컨트롤입니다.
